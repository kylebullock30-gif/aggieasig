01. Photos & banners

The labeled photo spaces are ready for your own images. Use JPG, PNG, WebP, or SVG files that you have permission to use.

  1. Place your image inside public/assets/images/ in the website source folder.
  2. Open public/assets/site-config.js and find the matching image slot below.
  3. Set its src to your image path, such as /assets/images/chapter-photo.jpg, and write a useful alt description.
  4. Save your changes and republish the site. The image will fill its slot automatically.

For the homepage banner, you can simply replace public/assets/images/home-banner.jpg with your own JPG using the same filename. Update the alt text in both site-config.js and index.html.

Images crop to fill their frames. Keep faces and important details near the center. Compress larger photos to roughly 500 KB when practical. Empty slots remain labeled until you add an image.

There is no live upload or public editing screen. These changes are made in your source folder and appear for everyone after you republish.

02. Social icon buttons

Open the socials list in public/assets/site-config.js. Replace href with the full address of your chapter’s Instagram or other profile. Update label to describe the destination.

To add a custom image icon, put it in public/assets/icons/ and set iconImage to its path, for example /assets/icons/instagram.png. Transparent PNGs or SVGs at 64 × 64 pixels work well.

Copy an entry to add another button, or remove an entry to remove a button. The included Instagram button points to the national organization until you supply the chapter’s profile.

03. Events & calendar

Edit public/assets/events-data.js. A commented example shows the format. Add real events inside the events array. Each event needs a unique id, a title, and a valid start and end. Available categories are Brotherhood, Philanthropy, and Chapter.

Use an ISO date with a Central Time offset: 2026-10-10T09:00:00-05:00. Use -05:00 during daylight saving time and -06:00 during standard time. Add location, description, and an optional rsvpUrl for your real registration page.

One event list powers the homepage, the event page, and the calendar. Past events remain visible on their calendar dates; the event page shows upcoming and ongoing events. Calendar export downloads upcoming events for importing into Apple Calendar, Outlook, or Google Calendar. This is a downloadable calendar file, not an automatic subscription.

No sample events are published. The calendar starts on the current month and shows an announcement message until you add dates.

04. Chapter store

The store checks the passcode on the server and uses an eight-hour, signed, HTTP-only session cookie. The catalog is sent only after successful access. “Lock store” clears the browser’s store session.

The initial passcode is in your separate Store Access handoff file. Change the secret named STORE_PASSCODE in your hosting settings and redeploy. Keep STORE_SESSION_SECRET private. Updating either secret invalidates existing store sessions.

Edit products in server/catalog.js. Each product has a name, description, image path, optional price, and orderUrl. Upload product photos to public/assets/images/ and use paths such as /assets/images/chapter-tee.jpg.

The three initial entries are a collection preview with no prices or active ordering. Add your actual inventory and a real ordering link to enable an “Order item” button. Payments are handled by your linked storefront; this site does not collect card information.

Files in public/, including product photos, can be accessed directly. Keep member records, confidential files, and private photos out of that folder. The protected catalog belongs in server/. The passcode requires the included server; simply uploading the HTML files to a static host will not provide store access.

05. Pages & colors

Page structure is in the separate HTML files in public/: index.html, about.html, philanthropy.html, calendar.html, events.html, and store.html.

Design is in public/assets/styles.css. The color variables at the top include cardinal #8d1935, stone #777572, and white #ffffff. JavaScript controls the navigation, images, event filtering, calendar, and store.

The shared header, footer, and icons live in public/assets/main.js. Chapter settings and social links are in public/assets/site-config.js. For a chapter rename, also update the text in the HTML pages.

The included README explains how to preview and republish the complete site. Changes made locally do not update the hosted site until it is republished.
